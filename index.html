HTML Fundamentals

HTML stand for HyperTextMarkUpLanguage. This is not a programming language. All it does is that it tells
a browser what content is on a page.

<Head>,<Body>,<HTML>

The<HTML> represents the entire webpage.

  • The<head>stores information about the page that isn't displayed to users.

  • The<body>contains content shown to users in the browser.

    • Links

    Links are function as little gateways to other pages.
    The link is created via the <href> atttibute.
    The link is then anchored with the <a> tag. Example: <a href = "https://www.example.com">Example Link</a>

    Tags

    Tags are the building blocks of HTML. They are used to create elements on a webpage. All tags are enclosed in angle brackets <> for the beginning and
    </> for the end. Most of elements require both of the beginning and closing tag.
    The <br> does not require a closing tag.
