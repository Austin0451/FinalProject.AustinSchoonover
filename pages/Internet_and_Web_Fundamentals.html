Internet and Web Fundamentals

Clients & Servers

All clients require information, in which they can through web browsers or mobile apps.
Servers stores data and provides services to the client.

IP Address

Identifies a device on a network with the help of a street address for a computer.

Domain's Names

A human friendly website address that is used to access a website. Examples are google.com and Amazon.com.
Domain names are easier to remember than IP addresses.

Protocol

A set of rules for communication. It allows devices to communicate with each other.
Examples of commonly used protocols HTTPS and HTTP.

Websites

A collection of wbe pages that provide information to clients via the web application.
Web applications are software that allows users to perform tasks.

Frontend and Backend

Frontend are what users see and interact with.
HTML, CSS, Javascript, buttons, menus, and pages are examples of frontend.
Backend are what users don't see. It is code that runs behind the scenes and handles the data, logic, and processing.
SQL,C++,C#,and Java are just one of the few many examples of backend.
